# Changelog

## 0.1.0 · 2026-11-24

First commissioning release.

- Read and watch BACnet/IP points, inspect device inventories, batch up to 32 property references, and read routed stations. Register with a BBMD to receive forwarded device announcements.
- Check staged BACnet/SC credentials offline and read a property through a primary or failover hub.
- Exercise supervised priority writes on the loopback simulator and export its capability worksheet.
- Inspect captured MS/TP frames and embed the reference responder without a global allocator.
